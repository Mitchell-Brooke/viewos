## ViewOS Trademark

**ViewOS** is a trademark of the ViewOS Project (jmultimate.com).

### Permitted Uses
- Referring to the distribution by name: "ViewOS", "ViewOS Linux"
- Describing software as "for ViewOS" or "compatible with ViewOS"
- Nominative fair use (truthful references)

### Prohibited Uses
- Using "ViewOS" in your own project/product name
- Using ViewOS logo/branding for unofficial builds
- Implying endorsement by ViewOS Project
- Modifying and redistributing as "ViewOS" without permission

### Derivative Distributions
If you create a derivative distribution:
- **Must not** use "ViewOS" in the name
- **Must** clearly state it is a derivative
- **Must** comply with Debian and KDE trademark policies
